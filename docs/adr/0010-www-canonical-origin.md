# 0010 - www.rebuild.us as the canonical origin

- Status: Accepted
- Date: 2026-09-03

## Context

The new Astro site is served from `www.rebuild.us`, while the apex `rebuild.us`
still serves the legacy WordPress site. Canonical tags, `hreflang` alternates,
and sitemap entries that point at the apex therefore send search engines to the
wrong (or 404ing) URLs.

## Decision

`https://www.rebuild.us` is the canonical origin for all SEO-facing URLs:
`canonicalUrl` and `alternateUrl` (en ↔ es hreflang) in `BaseLayout.astro`
callers, entries generated by `apps/web/src/pages/sitemap.xml.ts`, and the sitemap
reference in `apps/web/public/robots.txt`.

## Consequences

- Search engines index the new site regardless of what the apex domain serves.
- If the apex is later repointed at the new site, these URLs remain valid
  (www stays canonical); no migration is required, though the apex could then
  redirect to www.
- The values are hardcoded per page (not Sanity-managed); changing the canonical
  origin is a code change.
